## Como os writeups são organizados
Cada writeup segue o [modelo](TEMPLATE.md): objetivo, reconhecimento, exploração, causa raiz e como corrigir. A ideia é registrar o raciocínio, não só o payload.

## Ética
Todo o conteúdo vem de laboratórios autorizados e plataformas de treinamento. Não publico flags nem soluções de rooms ou desafios que as plataformas pedem para manter privados, e nada aqui deve ser usado contra sistemas sem autorização.
